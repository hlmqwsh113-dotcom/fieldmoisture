# 田间水分采集 App v4（Python/Kivy → 安卓 APK）

## 功能
- **全局明亮模式**：白色背景 + 深色文字（Kivy 默认是深色主题，已整体覆盖）
- **汉堡菜单**（顶部左侧三条横线）：导入表格 / 导出数据 / 退出
- **Excel 风格表格**：实线网格、行间无间距；数字小键盘同为实线无间距样式
- **App 专属文件夹**：首次启动自动创建 `手机存储/田间水分采集/`
  - 把 .xlsx 表格拷进该文件夹，App 文件选择器默认打开这里
  - 从别处导入的表格会自动复制进该文件夹集中管理（工作副本，自动保存写这里）
  - "导出数据"生成 `田间水分采集/导出/原名_已填写_时间戳.xlsx`
  - 安卓 11+ 无共享存储权限时自动回退 `Android/data/<包名>/files/田间水分采集/`
- 导入 Excel（.xlsx），表头：**田间条码（兼容旧表头"田间编号"）、排、区、品种名称、水分**
  （按表头名找列，不依赖列序；缺"水分"列保存时自动补）
- 默认只显示表格内容；点击数据行 → 弹出**数字小键盘**录入"水分"（0-9、小数点、删除、清空、确定）
- **连续录入**：确认后自动跳到下一个未填行继续弹键盘
- **搜索定位**：顶栏"搜索"，支持 ①田间条码关键字（部分匹配）②同时输入排/区号定位；
  跳转后该行**常亮高亮**（橙色）并自动滚动到屏幕中间
- **扫码定位**：顶栏"扫码"，调起 ZXing 兼容条码扫描器 App 扫**田间条码**，扫到即跳转高亮
  （需在手机上安装"条码扫描器"等 ZXing 兼容 App；桌面端提示改用搜索）
- **全局自动保存**：每次录入立即写盘 + 30 秒兜底定时保存 + 切后台/退出时强制保存，
  意外关机或卡死最多丢最后一条；状态行显示"已自动保存 HH:MM:SS"
- 行颜色：绿色=已填，橙色=定位/当前行，白色=待录

## 文件结构
```
main.py               # Kivy 界面 + 数字小键盘 + 搜索/扫码 + 自动保存
excel_io.py           # Excel 读写（与界面解耦，可单独测试）
app_paths.py          # App 专属文件夹（安卓/桌面自适应，可用 MOISTURE_APP_DIR 覆盖）
buildozer.spec        # 安卓打包配置（已含中文字体、存储权限）
assets/SimHei.ttf     # 中文字体（Kivy 默认字体不支持中文，必须打包）
.github/workflows/build-apk.yml   # GitHub Actions 云端打包（push 自动出 APK）
BUILD_APK.md          # 打包指南（GitHub Actions / WSL2 / Docker 三种方式）
tools/make_sample.py  # 生成示例表格 sample_田间水分.xlsx
tools/test_excel_io.py / smoke_ui.py / screenshot_list.py   # 测试与截图
```

## 桌面试运行
```bash
pip install kivy openpyxl
python tools/make_sample.py   # 生成新表头示例（田间条码+品种名称）
python main.py
```
桌面端专属文件夹在 `文档/田间水分采集/`（测试时可用环境变量 `MOISTURE_APP_DIR` 覆盖）。

## 打包安卓 APK
见 **BUILD_APK.md**。**本地一键打包**：双击根目录 `build-apk.bat`（自动走 WSL Ubuntu，
首次约 30-60 分钟，产物在 `bin\`，debug 包自动签名、无需证书）。
也可用 GitHub Actions 云端打包（push 后在 Actions 页面下载）。
产物：`bin/fieldmoisture-1.0-arm64-v8a-debug.apk`。

## 手机上使用
1. 把 .xlsx 拷到手机存储的 **田间水分采集** 文件夹（App 首次启动会自动创建）；
2. 菜单 → 导入表格（默认就在该文件夹里选）；逐行点击录入水分，或搜索/扫码定位；
3. 数据全程自动保存；回传电脑时点菜单"导出数据"，在 **田间水分采集/导出/** 里取文件；
4. 扫码前请先安装 ZXing 兼容扫码 App（如开源"条码扫描器"）。
